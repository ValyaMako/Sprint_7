
# Тестирование API
Этот проект предназначен для тестирования API учебного сервиса "Яндекс Самокат".

## Содержание

- Описание
- Установка
- Запуск тестов
- Структура тестов
- Примеры тестов



## Описание

Данный проект включает в себя набор тестов для проверки функциональности API. Тесты разработаны для обеспечения корректной работы API и выявления возможных проблем.

## Установка

Для запуска тестов вам потребуется:

1. Установить [Python](https://www.python.org/downloads/) 
2. Установить необходимые зависимости: pip install -r requirements.txt


## Запуск тестов
После установки зависимостей, вы можете запустить тесты с помощью команды: pytest tests/


## Структура тестов
Тесты организованы по следующим директориям:

tests/ - содержит все тестовые файлы.
Каждый файл теста содержит набор тестов для конкретного эндпоинта API:
tests/test_courier_login.py - логин курьера в системе
tests/test_create_courier.py - создание курьера
tests/test_create_order.py - создание заказа
tests/test_order_list.py - получение списка заказов

## Примеры тестов
Вот пример теста для проверки успешного ответа от API:

def test_create_order_with_choice_of_color(self, color):
    order_response = ApiMethods.create_order(color)
    assert order_response.status_code == 201
    assert "track" in order_response.json()

Этот тест проверяет, что при создании заказа с заданным цветом, API возвращает статус 201 и содержит поле "track" в ответе.
